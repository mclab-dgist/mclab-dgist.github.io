연구 그림은 대표그림: figure.webp로 연결되어 있습니다. 파일명을 바꾸지 않고 교체하거나, 새 파일명으로 값을 수정합니다. 이미지 연결은 파일명 기준입니다. PDF/사진에서 이름·논문 제목 등을 추측하는 기능은 없습니다.

기존과 같이 content/publications/ 및 content/projects/에서 정보·첨부 자료를 관리합니다. admin/info-helper.html로 info.txt 작성이 가능합니다.

PC 폴더만 바꾸면 공개 사이트는 바뀌지 않습니다. GitHub 저장소에 변경 사항을 Commit / Push 해야 합니다. 공개 GitHub 저장소에 올린 파일은 공개: false이더라도 저장소 자체에서 보일 수 있으므로 비공개 개인정보·계약서는 올리지 마세요.

5. 미리보기와 검증

제공된 단일 파일 MCLab_Original_Photos_Preview.html은 사진이 포함된 대화형 미리보기입니다. Chrome 또는 Edge에서 열어 확인합니다. 해당 파일은 자료 수정 후 자동 재생성되지는 않습니다.

python -m unittest discover -s tests -v
python scripts/build_site.py
python scripts/build_preview.py --output MCLab_Preview.html

실제 배포 자료는 _site/에 새로 생성됩니다. 저장소의 data/site-data.js는 처음 받은 상태를 로컬에서 확인하기 위한 스냅샷이며, 자동 배포는 이 스냅샷 대신 content 폴더를 다시 읽습니다. 이전 미리보기 대신 이번 파일을 사용하세요.

자동 정보처리 회귀 테스트와 Chromium에서 8개 화면·13개 인물 사진·11개 연구 그림·8개 갤러리, 검색·확대·모바일 메뉴 등을 점검했습니다. 상세 결과는 docs/UNIT_TEST_RESULTS.txt, docs/BROWSER_VERIFICATION.json, docs/BUILD_REPORT.json을 참조하세요.

실행 환경의 파일/HTTP 탐색 정책 때문에 브라우저 검수는 동일한 소스와 이미지를 내장한 미리보기를 인라인으로 로드하여 수행했습니다. 로컬 파일 경로는 별도로 검증했습니다. 실제 GitHub Actions 실행, 라이브 주소 및 모든 브라우저의 호환성을 검증했다는 의미는 아닙니다.
