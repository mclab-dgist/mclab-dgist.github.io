MCLab 원본 사진 버전 설치 안내

대상 저장소: nkh6189-sys/mclab-dgist.github.io

자동 설치 설정은 저장소에 반영되었습니다. 홈페이지 본체와 사진 ZIP의 업로드는 아직 필요합니다.

최초 한 번만 진행하세요

  1. 저장소 main 브랜치에서 Add file → Upload files를 엽니다.
  2. MCLab_Original_Photos_No_Teaching.zip 파일 하나를 업로드합니다.
  3. 압축을 풀거나 이름을 바꾸지 말고 Commit changes를 누릅니다.
  4. Actions → Install and deploy MCLab에서 검사와 배포 결과를 확인합니다.

이 저장소의 설치기는 ZIP을 mclab 폴더에 한 번만 풀어 저장합니다.

이후에는 mclab/content 아래의 학생, 논문, 과제 정보와 사진을 수정하고 Commit하면 됩니다.

Teaching은 새 홈페이지의 메뉴와 배포 파일에서 제외됩니다.

처음 받은 ZIP이 이후에 수정한 학생·논문·과제 정보를 덮어쓰지 않도록 구성했습니다.

Pages 설정

기존 gh-pages 브랜치 배포 방식을 사용합니다.

Settings → Pages → Deploy from a branch → gh-pages → /(root)를 확인하세요.

이전 일반 안내서의 GitHub Actions 직접 배포 방식 대신 이 저장소 전용 설치 안내를 따르세요.
