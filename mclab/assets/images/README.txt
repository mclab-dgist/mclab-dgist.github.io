Image slots / 사진 파일 위치

No portraits or lab photos were downloaded. Google Sites image endpoints were inaccessible during the migration. Initials and an original vector illustration are used instead.

1. Save PI/member portraits under people/, e.g. people/kanghyun-nam.jpg.
2. Set pi.photo or the relevant people[].photo to assets/images/people/kanghyun-nam.jpg.
3. Save a hero photo here and set config.heroImage to assets/images/your-photo.jpg.
4. Save gallery photos under gallery/ and add gallery records in the editor.

Recommended image sizes: portraits 800 x 1000 px; hero 1600 x 1200 px; gallery 1600 px wide. These are design recommendations, not file restrictions.
Use only photos you are authorized to publish, with subjects' permission.
