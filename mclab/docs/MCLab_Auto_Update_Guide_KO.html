MCLab 정보 업데이트 안내

현재 승인된 원본을 수정하고 검증하는 관리 절차

2026-11-22 현재 기준: main 브랜치의 mclab/content/만 공개 정보의 수정 원본으로 사용합니다.
과거 ZIP·미리보기·별도 데이터 사본으로 현재 내용을 덮어쓰지 않습니다. gh-pages와 _site/는 자동 생성 결과이며 직접 수정하지 않습니다. 상세 운영 기준은 README_KO.md를 따릅니다.

1. 현재 정보의 원본

대상 저장소는 mclab-dgist/mclab-dgist.github.io, 공개 홈페이지는 https://mclab-dgist.github.io/입니다. 아래 경로는 모두 저장소의 mclab/ 폴더 기준입니다.

수정 대상원본
기본 설정·연구 프로그램content/site.json
교수·구성원 정보와 사진content/people/<id>/
연구 설명과 대표 그림content/research/<id>/
논문·과제content/publications/<id>/, content/projects/<id>/
소식·갤러리content/news/<id>/, content/gallery/<id>/

현재 목록에 포함된 과거 연도 논문과 종료 과제는 계속 보존합니다. 오래된 버전 정리는 연구실적을 연도 기준으로 삭제하는 작업이 아닙니다.

2. 사진·그림의 출처와 인물 확인

기존 원본 사진과 웹용 사본의 대응 기록은 ORIGINAL_PHOTO_MAPPING.csv 및 ORIGINAL_PHOTO_MAPPING.json에서 확인합니다. 이 기록은 사진 출처 확인용이며 현재 구성원·연구 목록의 원본은 아닙니다.

파일명만으로 신원을 확정할 수 없는 사진은 다른 사람의 이름으로 임의 연결하지 않습니다. 초기 사진 대조가 필요하면 사진 이름 확인 자료를 참고하되, 현재 연결 상태는 해당 content/people/<id>/info.txt와 직접 대조합니다.

3. 변경 반영 원칙

  1. 최신 main과 공개 홈페이지를 확인한 뒤 요청받은 원본 항목만 수정합니다. 예전 패키지를 업로드하거나 폴더 전체를 덮어쓰지 않습니다.
  2. 의도한 변경을 검토한 뒤 quality/approved-baseline.json의 해당 항목만 함께 갱신합니다. 승인 기준 전체를 자동 재생성하거나 검증을 우회하지 않습니다.
  3. 아래 테스트·빌드·승인 검증과 화면 확인을 마칩니다.
  4. 승인된 변경을 반영한 후 GitHub Actions와 공개 홈페이지를 확인합니다. 로컬 파일 수정이나 빌드 성공만으로 공개 반영을 단정하지 않습니다.

설치 표식 .mclab-import.json, 설치 도구, 배포 워크플로는 유지합니다. 과거 설치 묶음으로 다시 설치하는 절차는 일상적인 업데이트에 사용하지 않습니다.

4. 사진·정보 파일 수정

content/people/학생-id/
  info.txt
  photo.jpg

content/research/연구주제-id/
  info.txt
  figure.webp

content/gallery/사진-id/
  info.txt
  photo.jpg

예: content/people/minhyeong-kim/photo.jpg를 교체하되 연결 파일명을 유지하면 기존 참조를 사용할 수 있습니다. 이름·확장자가 바뀌면 info.txt의 사진: 또는 대표그림: 값도 함께 수정합니다. 실제 연결 상태를 확인하고 사진 내용만으로 이름이나 논문 제목을 추측하지 않습니다.

admin/info-helper.html은 정보 파일 작성 보조 도구입니다. 작성한 내용을 해당 원본 파일에 반영하고 같은 검증 절차를 따릅니다.

공개 가능한 정보·사진만 올리세요. 공개: false는 홈페이지 표시만 제어하므로 공개 GitHub 저장소에 올린 비공개 개인정보·계약서를 보호하지 않습니다.

5. 새 빌드의 미리보기와 검증

Python 3.11 이상을 사용합니다. 저장소 루트에서 다음 명령을 실행합니다.

cd mclab
python3 -m unittest discover -s tests -v
python3 scripts/build_site.py
python3 scripts/verify_approved_release.py

미리보기는 방금 생성한 _site/ 또는 그 결과로 새로 만든 단일 HTML만 사용합니다. 원본 HTML을 직접 열거나 예전에 생성한 미리보기를 재사용하지 않습니다.

python3 -m http.server 8000 --directory _site

위 서버의 http://localhost:8000/에서 확인할 수 있습니다. 별도 단일 파일이 필요하면 빌드 후 생성합니다.

python3 scripts/build_preview.py --output /tmp/MCLab_Preview.html

생성 결과와 미리보기는 수동 편집하거나 커밋하지 않습니다. 과거 보고서의 성공 기록은 현재 검증을 대신하지 않습니다. 검증 실패 시 원본 또는 해당 변경의 승인 여부를 확인하고 배포를 중단합니다.
