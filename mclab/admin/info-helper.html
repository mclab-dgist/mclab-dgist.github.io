이 도구는 GitHub에 로그인하거나 업로드하지 않습니다. 만든 파일을 안내된 저장소 폴더에 넣고 Commit / Push하면 GitHub Actions가 홈페이지를 갱신합니다. 공개: false는 홈페이지에서만 숨깁니다. 공개 저장소에 비밀 자료를 넣지 마세요.

기존 원문서지·순위 등 추가 필드는 누락되지 않도록 보존합니다.
